# v0.1.0 — retinal omission and calibration transfer

**Local release candidate. Public publication, release date and release URLs are pending.** The package version is prepared as 0.1.0; no public tag is implied by this document.

The first release studies **retinal optic-cup segmentation, Chákṣu → RIGA**. It asks how omission tolerance, expert disagreement and calibration transfer affect the size of a predicted region. On the same 182 RIGA evaluation images, recalibration of a frozen scorer lowers omission from 19.4384% to 3.4541% at the 5% budget, while mean region area expands 4.88-fold.

## Included

- A standalone exact integer/rational implementation of bounded monotone expectation conformal risk control, with the preserved TypeScript reference and a synthetic spatial example.
- Two 1,001-candidate aggregate calibration curves and **eight exact final calibration replays**. RIGA's four transferred policies reuse the Chákṣu decisions and are not extra calibrations.
- **902 warm-up aggregate runs**: 501 Chákṣu and 401 RIGA, with regenerated descriptive percentiles and separate single full-pool results.
- Both generated study reports, protocols, expert/device/source slices and five SVG/PNG figure pairs with verifiable plotted inputs.
- Citation metadata, Apache-2.0 scope and upstream credit, dependency lock, source archive/wheel checks, and a prepared Linux/macOS/Windows workflow.

## Reproduce

From an unpacked source archive:

```sh
python -m pip install .
rcms verify
rcms chaksu --output results/chaksu
rcms riga --output results/riga
python -m pip install ".[figures]"
rcms figures --output results/figures
rcms verify-figures docs/figures/plot_data.json
```

The base package needs Python 3.11+ and has no third-party runtime dependencies. Figures add Matplotlib/NumPy. Use the [complete locked reproduction procedure](../reproduction.md) for source/wheel isolation and verification. The wheel includes the package, aggregate evidence and figure generator; the source archive also includes reports, ready-rendered figures, tests, reference engine and documentation.

## Scope and limitations

This artifact reproduces calibration and aggregate evidence. It does not run model training or image-level inference. Source images, overlays, reconstructed study masks, scores, per-image rows, role assignments and model weights are excluded. PolypGen is not in v0.1.0.

The method concerns expected image-average omission under assumptions; it does not supply a per-image, worst-expert, subgroup, patient-level or clinical guarantee. A source calibration certificate does not transfer to RIGA. Chákṣu's observed 5%/10% exceedances, RIGA's local Magrabi exceedance and development variability remain visible.
